Установка (рекомендуется)
-------------------------
1. Запустите ChyguiSlide-{VERSION_LABEL}-Setup.exe от имени администратора.
2. Установщик поставит программу в:
     C:\Program Files\ChyguiSlide
3. Ярлык появится в меню «Пуск» (и на рабочем столе — если отметите).

Обновление: запустите новый Setup — файлы в Program Files заменятся.
Удаление: «Параметры → Приложения» или ярлык удаления в меню «Пуск».
База песен и настройки при удалении программы НЕ удаляются.

Установка из ZIP (без установщика)
----------------------------------
1. Распакуйте архив в любую папку (например C:\Programs\ChyguiSlide).
2. Запустите ChyguiSlide.exe в корне папки.

Структура папки программы
-------------------------
  ChyguiSlide.exe   — запуск
  app\               — программа и библиотеки
  README.txt

При первом запуске создаётся чистая база и подтягивается сборник
«Песнь возрождения». Библия (RST) уже входит в программу.

Данные пользователя
-------------------
База песен и настройки хранятся отдельно от программы:
  %LocalAppData%\ChyguiSlide

В релиз ваша рабочая база и настройки НЕ входят.

NDI (опционально)
-----------------
Для приёма NDI-видео установите NDI Tools:
  https://ndi.tv/tools/

Требования
----------
Windows 10 (версия 19041+) или Windows 11, 64-bit.
.NET и Windows App SDK уже входят в эту сборку.
