# Чугуй Слайды

Программа для проекции на богослужении: песни, Библия и объявления на второй монитор. Работает локально на Windows, каталог хранится у вас на компьютере.

Разработано для церкви евангельских христиан-баптистов Т9 (г. Ростов-на-Дону).

---

## Для кого

Для оператора трансляции / проектора: быстро найти песню или стих, собрать плейлист и вывести текст на экран зала — с оформлением, обоями, анимированным фоном.

---

## Возможности

### Проекция

- Отдельное полноэкранное окно на выбранном мониторе (рендер через WebView2)
- Показ песен, Библии, объявлений и медиа из плейлиста
- Горячие клавиши
- Быстрый плейлист на службу + сохранение именованных плейлистов
- Режимы текста: крупный шрифт, перенос, авторастягивание слов на всю ширину экрана
- Переходы: без анимации, Crossfade, Slide, Stagger и другие стили
- Поля (отступы) проекции настраиваются в настройках
- Опция «Держать фон на экране» после завершения показа (только при втором мониторе)



### Песни

- Каталог со сборниками, поиском по названию и тексту
- Сортировка по названию или номеру
- Редактор: куплеты и припевы, порядок секций, кнопка «припев после каждого куплета»
- Предпросмотр слайда как на экране (lookahead) рядом со списком секций
- Статистика на обзоре: какие песни чаще показывали



### Медиа в плейлисте

- Фото и видео в быстром плейлисте (MP4, MKV, AVI и изображения)
- Воспроизведение только по «Начать показ» / горячей клавише (не при выборе в списке)
- Добавление нескольких файлов сразу, переименование и удаление
- Крупные видео без полной копии в AppData: ссылка + воспроизведение через WebView2
- Автоматический запасной путь, если файл нельзя отдать в WebView



### Импорт

- Сборники **SoftProjector** (`.sps`) —  «Песнь возрождения 3300» загружена на старте
- Презентации **PowerPoint / LibreOffice** (`.pptx`, `.odp`)
- Импорт песни с сайта по URL (в первую очередь сделана поддержка holychords.pro без аккордов)



### Библия

- Встроенный **Синодальный перевод**
- Навигация: цветные плитки книг (ВЗ / НЗ) → сетка глав → стихи
- Поиск по ссылке (`2пар 15 8`) или по тексту
- Проекция с выбранного стиха
- Подпись ссылки на экране: положение и выравнивание
- Предпросмотр стиха как на экране



### Объявления

- Быстрые слайды: заголовок + текст → сразу на экран или в постоянные
- Постоянные объявления: создание, редактирование, закрепление
- Предпросмотр слайда как на экране



### OBS / стрим в локальной сети

- Передача текста слайдов на другой ПК по HTTP (для [OBS](https://obsproject.com/) Browser Source)
- URL и порт задаются в настройках; на этом же ПК есть локальный адрес для проверки
- Опциональный полупрозрачный фон под текстом
- Размер шрифта и перенос подстраиваются под размер источника в OBS



### Оформление (стили)

- Несколько пресетов оформления
- Шрифт, цвет текста и фона, выравнивание, обводка
- Обои: изображения и видео
- Общий пул обоев или отдельно для песен и Библии
- Фиксированный фон или случайный при старте проекции



### Камера и NDI (Функционал в разработке)

- Показ видео с Android-камеры по сети (TCP)
- Приём **NDI** (например из OBS) — нужен [NDI Runtime](https://ndi.video/)
- Переключение на камеру / NDI прямо из раздела «Трансляция»

Функция для возможности вывода изображения с камеры на экран



### Горячие клавиши

Переназначаемые в настройках:

- начать показ
- завершить показ
- следующий / предыдущий слайд



### Резервные копии

- Копия каталога на **Яндекс.Диск** (OAuth) или в локальную папку
- Восстановление из облака
- Автобэкап по расписанию, пока программа запущена



### Интерфейс и обновления

- Новый интерфейс: верхнее меню и трёхколоночные экраны (песни, Библия, объявления, трансляция)
- Единая тёмная палитра для Обзора, Настроек и новых разделов
- Тема окна оператора: как в системе / светлая / тёмная
- Проверка обновлений через GitHub Releases (канал beta / release)

## Требования

- Windows 10 (19041+) / Windows 11
- Рекомендуется x64
- Для NDI — установленный NDI Runtime
- Для автообновления через установщик — права администратора при установке

## Установка и запуск



### Готовый установщик

Скачайте `ChyguiSlide-*-Setup.exe` со страницы [Releases](https://github.com/DjgaaD/ChyguiSlide/releases) и установите (нужны права администратора).  
Программа ставится в `Program Files\ChyguiSlide`.

### Разработка

```powershell
.\run.cmd
```

или

```powershell
dotnet run --project .\ChyguiSlide.csproj -p:Platform=x64
```

Сборка установщика:

```powershell
.\scripts\Publish-Release.ps1
```

Нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php).
